帮我用Go语言实现一个多模态混合向量检索与图文知识库系统（Mini Milvus + RAG 闭环）

业务背景：现代 AI 应用不仅需要搜索文字，还需要搜索图片、音视频（多模态）。该系统将文本向量和图片特征混合存储，并在前端提供"以图搜图"、"以文搜图"以及"智能知识库问答"的精美工作台。

前端页面 (Vue 3 + TailwindCSS + 瀑布流组件)：混合搜索主页：支持输入框文字搜索，或者拖拽一张本地图片到输入框。多模态结果呈现墙：根据相似度评分（Score）从高到低排列，鼠标悬停在搜索结果（图片/文档段落）上，高亮显示匹配的特征区域。

Go 后端核心实现：高维向量内存索引：手写或集成一个轻量级的向量检索算法（如基于 IVF-FLAT 或 HNSW 核心概念的 Go 实现），处理千维向量的余弦相似度（Cosine）或欧氏距离（L2）并发计算。混合倒排索引路由：实现"标量（关键词）+ 矢量（向量）"的混合查询（Hybrid Search），将文本分词检索与特征向量检索的结果进行 RRF（倒数排名融合）算法合并。数据段（Segment）写入管道：维护内存 Buffer，当数据达到指定大小（如 64MB）时，触发 Goroutine 异步构建索引并持久化到磁盘。

文件数与代码量：约 40+ 个 Go 文件，代码量 7000 - 9500 行。
